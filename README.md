

# Project Overview

This project analyzes employee attrition data to understand employee turnover and identify the key factors associated with attrition.

An interactive dashboard was created using Microsoft Power BI, with data preparation and analysis performed using Excel.

# Project Objectives

- Analyze overall employee attrition.
- Identify departments and job roles with higher attrition.
- Analyze attrition based on age, gender, education and job role.
- Understand the impact of employee satisfaction and experience.
- Identify patterns that can help HR teams understand employee turnover.

 Tools & Technologies

- Microsoft Excel – Data cleaning and preparation
- Power BI – Data analysis and interactive dashboard
- DAX – Calculations and KPIs

# Key KPIs

- Total Employees
- Total Attrition
- Attrition Rate
- Average Employee Age
- Average Monthly Income
- Average Years at Company

 # Dashboard Analysis

The dashboard provides analysis of employee attrition across different dimensions, including:

- Department
- Job Role
- Age Group
- Gender
- Education
- Job Satisfaction
- Years at Company
- Monthly Income

  # Key Insights

The analysis helps identify patterns in employee attrition and provides a better understanding of the factors associated with employee turnover.

These insights can support HR teams in identifying areas that may require further investigation and developing data-driven employee retention strategies.
